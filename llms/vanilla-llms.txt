# Vanilla

> Vanilla (Vanilla Technologies Inc., justvanilla.com) is an estate planning platform for financial advisors, RIAs, and wealth management firms. It provides AI-powered estate document analysis and health assessments, estate visualization, scenario modeling for tax strategies, and estate document creation. Vanilla is SOC 2 Type II audited and integrates with wealth platforms including Salesforce, Orion, Black Diamond, Addepar, eMoney, and Plaid. Vanilla does not currently publish a public developer portal, API documentation, or client SDKs; api.justvanilla.com exists (AWS API Gateway) but is private.
